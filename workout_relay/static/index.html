JSON v1

A predictable format for reliable workouts

Workout Relay does not ask an AI to interpret your plan at upload time. Every duration, target, repeat, and date is explicit, validated, and deterministic.

View complete example View JSON Schema

Required structure

{
  "schema_version": 1,
  "plan_id": "2026-W40-5k",
  "title": "5K development week",
  "workouts": [ ... ]
}

A plan contains one or more dated running workouts. Unknown fields are rejected so mistakes are visible.

Durations

{ "type": "time", "value": 600 }
{ "type": "distance", "value": 1000 }

Time is always seconds. Distance is always metres. Values must be positive whole numbers.

Targets

{ "type": "no_target" }
{ "type": "heart_rate", "low": 135, "high": 150 }
{ "type": "pace", "slow": "5:30", "fast": "5:10" }

Use one target per step. Pace is minutes per kilometre; slow must genuinely be slower than fast.

Repeats

{
  "type": "repeat",
  "count": 6,
  "steps": [ ... ]
}

A repeat contains 1–5 simple steps. Repeats cannot be nested, and the expanded workout cannot exceed 50 steps.

Reliability checklist

  • Use a distinct ID for each different workout; reuse that ID when editing or rescheduling it.
  • IDs identify a workout across your whole account, not just within one plan.
  • Garmin workout titles contain at most 50 characters.
  • Call the validation endpoint before submitting an automatically generated plan.
  • Send raw JSON—not Markdown code fences or explanatory text.

MCP

Connect an assistant

Add this address as a connector in Claude or ChatGPT. You sign in here once and approve; the assistant never sees your Garmin or Workout Relay password.

In Claude

  1. Open Settings, then Connectors, and choose Add custom connector.
  2. Paste the address above and add it. Leave the advanced OAuth fields empty.
  3. Adding a connector may need a browser rather than the phone app; once added it works in any chat.

In ChatGPT

  1. Paid plans: open Settings, then Security and login, and turn on Developer mode. Connectors then accept a custom server address.
  2. Add the address above as a custom connector and approve the sign-in.
  3. Free plans do not offer custom connectors. Use the Upload tab on this site, which needs no connector.

Either way you will be asked to sign in to Workout Relay and approve the connection. Then ask the assistant to build a plan and send it.

API

Assistant access

For a custom GPT or your own scripts, create a revocable bearer key. Add it only to the tool's protected API-authentication field—never paste it into a chat. The full key is shown once. Claude cannot use a bearer key: connect it with the connector above.

HTTP

Recommended API workflow

  1. Fetch the format instructions and JSON Schema.
  2. Generate a plan as raw JSON.
  3. POST it to /api/v1/plans/validate.
  4. Fix every structured validation error.
  5. POST the valid plan to /api/v1/plans.
  6. Poll the returned submission URL until it is completed or failed.

Before connecting

This uses an unofficial Garmin integration. Your credentials pass through Workout Relay once and are not stored. Encrypted session tokens provide ongoing account access.

Because the operator controls the hosted server, use this service only if you trust its operator. Encryption protects stored data, but cannot protect against malicious server code.
